# 同频移动端 PWA 前端

这是面向 iPhone 纵向比例的用户端单页 PWA。首页以晨光房间和小频为主视觉，用户可以从陪伴入口进入聊天、日记、设备趋势、活动关怀、舒缓跟练、人工支持、现实资源和可选自评；页面通过 `api.js` 使用真实后端接口。

## 本地打开

为使 Service Worker 和“添加到主屏幕”配置生效，请通过本地服务器或 HTTPS 访问，而不要直接双击 HTML 文件。

```bash
cd /Users/Amin/Desktop/同频
python3 -m http.server 8766
```

随后打开 `http://127.0.0.1:8766/HoldU/frontend/mobile-pwa/`。线上用户端入口为 `http://8.133.215.80:8080/api/v1/docs/mobile-pwa/`。部署到 HTTPS 后，可在 iPhone Safari 选择“分享 -> 添加到主屏幕”，以独立轻应用方式运行。

页面由后端直接托管时，会自动使用同源 API 地址；本地静态预览才默认指向远程 API。也可通过页面地址追加 `?api=https://你的服务/api/v1` 覆盖。首次打开会创建匿名用户会话，令牌只保存在当前浏览器会话中。

## 目录

- `index.html`：用户端界面结构、移动端样式与 PWA 元信息
- `app.js`：用户端交互状态与 PRD 流程
- `api.js`：用户端真实接口适配器，负责匿名会话、鉴权、请求错误和接口路径映射
- `manifest.webmanifest`、`sw.js`：PWA 清单与离线缓存
- `assets/`：小频的安静/回应状态、场景背景和应用图标
- `DESIGN.md`：色彩语义、动效和安全文案边界

页面不包含真实危机数据，也不替代专业心理或医疗服务；不会自动报警、外呼、通知家属或宣称已有真人接管。用户内容由后端按接口权限保存，匿名会话令牌只保存在当前浏览器会话内。
